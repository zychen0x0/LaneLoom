# 曲线查询迭代过程（仅 SVG）

在仓库根目录运行：

```bash
python vis/output/visualize_query_stages.py
```

默认使用 20260924_174958 实验的 `best_OpenLaneOfficial_F1_epoch_43.pth`，
配置直接读取 checkpoint。默认三个样本为 `150914058009157400`、
`155294852943939800` 和 `150733834142979700`。

每个样本只输出一张图：
`vis/output/query_stages/openlane/<segment>/<frame>/query_refinement.svg`。
不输出 PNG、PDF、JSON、NPZ，也不生成独立 GT 图。图形 QA 在临时目录中进行，
结束后自动清理。可用 `--images <路径> ...`、`--checkpoint <路径>`、
`--config <路径>`、`--device cuda:0`、`--output-root <目录>` 指定输入。
布局针对默认 checkpoint 的两层解码器。
指定单个样本时，可额外传 `--reference-ply <路径>`，将对应的 PLY 与回溯 Q0
叠加在左上角；该参数只用于展示，不改变模型推理输入。实际推理仍使用配置中
的点云加载与时序累计。点云栅格层嵌入 SVG，曲线与文字保留矢量。

## 图的内容

- 第一列：点云 BEV 特征的通道绝对值均值、BEV 预测的 5 个相对曲线模板、
  模板高度，以及 query 与 GT 的配对误差变化。
- 后三列的上三行：同一 source query ID 的 Q0 初始曲线、第一次 FV + BEV
  联合修正、第二次联合修正；分别显示相机投影、BEV 曲线与高度。
- 最后一行的后三列：同一已训练模型只保留前视采样证据、只保留 BEV 采样证据、
  保留两路证据时的最终车道预测，用于检查采样证据的影响。

GT 只作为虚线参照；曲线 query 是彩色实线，同一 query 在前三个阶段保持同色。
Q0 BEV 面板额外用浅色显示全部 505 条候选；相机投影和粗线仍只回溯最终检测
或明确标注的低分候选，不能把这些粗线理解为全部 Q0。全量覆盖以全部候选在 GT 支持范围内的距离计算。
图显示真实模型输出，不对 query 做二次拟合，也不手动移动曲线使其趋近 GT。
不可见 anchor 保留为断点。每阶段是否改善以实际误差和曲线为准，不预设单调收敛。

## 对应的模型流程

CQG 从点云 BEV 预测 5 个相对模板，101 个横向位置将它们扩展为 505 条 Q0
候选。第一层修正后筛选 64 条，第二层在更新后的曲线上重新采样并修正。
最终按 checkpoint 的分数阈值 0.5、可见阈值 0.5 与 NMS 输出车道。
前视和 BEV 证据在每一层一起参与 cross attention，因此迭代列均为联合修正。

图沿最终检测的 query 回溯，不按 GT 误差挑选 query。三个阶段统一使用最终
预测的可见范围，避免将可见范围变化误当成几何修正。这个条件选择有助于追踪
同一曲线，但不能估计全部 505 条初始候选的召回或质量。
如果没有检测通过阈值，则显示最多 5 个分数最高、有至少两个可见 anchor 的
候选，并在图中明确标注为低分候选。如果所有候选均无两个可见 anchor，才使用
最高分候选的完整 y 范围。采样干预图同样区分正式检测与低分候选。

误差使用最终预测与 GT 的 Hungarian 一对一配对，不设置距离阈值。
每对至少两个共享可见 anchor，且只在 GT 实际 y 范围内评估，不向外外推。
所有阶段固定配对与支持范围；误差曲线为各配对平均 xz 距离的均值。
图底部报告未配对的 GT 数量。该误差是样本级描述性诊断，不是官方 F1。

该 checkpoint 开启 RGB point painting，并使用 10 m、5 m 历史采样；初始
BEV 已含投影 RGB，不能称为纯 LiDAR 或单帧实验。BEV 灰度图是特征绝对值均值，
不是车道概率或注意力图。相对模板的横向原点为 0，不直接与绝对位置 GT 比较。

仅前视/仅 BEV 对照屏蔽 sampler 的对应 key padding mask，保留 decoder null
证据；权重和初始 BEV 不变。各干预独立运行完整 decoder，筛选路径可能不同。
它们是推理干预，不能代替重新训练的消融实验。这三个样本展示模型的具体行为；
模块有效性是否普遍成立，还需结合验证集指标。

## 本次真实推理结果

三个样本使用同一 epoch 43 checkpoint，结果均已生成。
每张 SVG 的面板对齐、临时 PDF 字号与文字碰撞检查已通过，并逐图查看。

| Sample | Q0 → Iter 1 → Iter 2 平均配对 xz 误差（m） | 联合模型最终检测 |
|---|---|---|
| 150914058009157400 | 0.332 → 0.089 → 0.075 | 7 条；配对 7 条，GT 未配对 2 条 |
| 155294852943939800 | 5.227 → 5.178 → 5.009 | 0 条；图显示 5 个低分候选 |
| 150733834142979700 | 0.701 → 0.173 → 0.119 | 5 条；配对 5 条，GT 未配对 1 条 |

两个样本展示了明显的几何修正。雾天弯道样本 `155294852943939800` 的
预测模板和 query 回归较差，不能作为模型成功修正的例子。
其中五个低分候选被 Hungarian 强制一对一配对到五条 GT，所以误差较大；
该配对不代表它们已被成功检测，也不代表正确的车道语义对应。

## 单独论文面板：相机三阶段 + 点云 BEV

对已有 `query_refinement.svg`，使用 `export_query_stage_panels.py` 可只新增四张
独立 SVG，保存在原有 `<segment>/<frame>/` 目录中：

- `01_q0_camera.svg`
- `02_iteration_1_camera.svg`
- `03_iteration_2_camera.svg`
- `04_pointcloud_bev.svg`

相机面板保留完整原始照片及原始尺寸（1920×1280），不显示阶段标题或顶部白边。曲线统一为 `#00ff66`、6 单位宽的实线；
右上角只显示 `Pred` 图例，不绘制 GT。三个阶段复用原诊断图中的同一组
tracked query，不按阶段重新挑选最接近 GT 的曲线，不重新推理或拟合。
矢量坐标从原 SVG 的相机变换恢复，保留可见性断点；照片从原文件重新读取，
不使用诊断图中的低分辨率缩略图。

BEV 从原 PLY 的全部有限 xy 点重新绘制，保留 RGB，按 x=[−25,25] m、
y=[0,100] m 的视窗裁切，不下采样。画布和绘图区尺寸与 `--bev-reference`
完全一致；只保留坐标轴、刻度与网格，没有标题、GT/query 曲线或图例。

```bash
python vis/output/export_query_stage_panels.py \
  --source-svg <sample目录>/query_refinement.svg \
  --image <原始照片.jpg> \
  --reference-ply <对应点云.ply> \
  --bev-reference <参考04_bev.svg>
```

`--qa-dir <临时目录>` 可保留 PDF、PNG 预览以及对齐/碰撞检查记录。
未指定时 QA 中间文件自动清理，sample 目录只新增上述四张 SVG。
原有诊断总图保留，其他独立面板暂不导出。各 SVG 是独立单面板，
不对多图拼版作对齐声明。仅输出 SVG，因此不要求 TIFF。点云栅格按 600 DPI
导出，点的面积为 0.8 pt²；临时 QA 预览为 300 DPI。文字和曲线保持矢量。
照片保留原始 1920×1280 像素：有效 PPI 取决于论文中的放置尺寸，宽度
不超过 81.28 mm 时可达到 600 PPI。调高 savefig 的 DPI 不会增加照片的
原始细节，不能把插值放大视为新增的真实分辨率。

## 其余八张独立几何面板

```bash
python vis/output/export_query_geometry_panels.py \
  --source-svg <sample目录>/query_refinement.svg \
  --bev-reference <sample目录>/04_pointcloud_bev.svg
```

在同一 sample 目录新增 `05_relative_templates_bev.svg`、`06_q0_bev.svg`、
`07_iteration_1_bev.svg`、`08_iteration_2_bev.svg`、`09_template_height.svg`、
`10_q0_height.svg`、`11_iteration_1_height.svg`、`12_iteration_2_height.svg`。
全部去掉标题和误差文字。模板按 tracked Pred 的真实来源统一配色：使用到的
模板为绿色 `#00ff66`，其余模板采用蓝/紫/灰等非红、非绿色；两张模板图
使用相同映射。模板来源从原图 query ID、Q0 候选的模板家族颜色和每模板
seed 数量交叉核对。该 sample 的 q465 来自第 5 个模板，q52、q40、q56
来自第 1 个模板，因此第 1 和第 5 个模板均标绿。GT 为 `#ff3b30` 实线，tracked
Pred 为 `#00ff66` 实线，线宽 2.5 pt。独立 Q0 BEV 只保留最终 NMS
选中的 4 条 query 在 Q0 阶段的原始曲线与 4 条 GT，不绘制 505 条背景候选；
原始诊断总图保留全量候选，用于模板来源核对。
对照图的 GT/Pred 图例统一放在绘图区右上角，竖向排列，采用白色底框。

四张 BEV 的画布为 398.836875×725.967734 pt，绘图区为 332.18×664.36 pt，
与点云参考完全相同。四张 BEV 均使用 x=[−25,25] m、y=[0,100] m，
横坐标标签统一为 x / m，且横纵等比例；模板坐标仍是相对位置，未平移曲线。
四张高度图画布为
398.836875×227.697734 pt，绘图区为 332.18×166.09 pt；四张高度图统一
使用 Q0 高度图的 z 范围（约 −0.72949～0.19087 m），刻度为 −0.6、−0.4、
−0.2、0.0。超出纵轴范围的模板线段按视窗裁切，原始曲线数据不变。
横轴 y=[0,100] m。八张独立几何面板中的模板、GT、Pred 曲线和文字
均保持矢量，无嵌入栅格。

坐标通过原 SVG 的刻度标定恢复，并核对全部刻度的线性映射；只调整样式与
布局，不重新推理、不拟合、不更换 query。`--qa-dir` 用法与前四张一致。
字号、单面板布局和最终 PDF 碰撞检查使用公共导出函数；静态检查需同时
检查本脚本与 `export_query_stage_panels.py`，以覆盖导入的字体/导出设置。
